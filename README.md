# CRUD FIFA (Windows Forms & MySQL) 🎮⚽

Este é um projeto prático desenvolvido em C# com Windows Forms e banco de dados relacional MySQL. O grande diferencial desta aplicação foi a velocidade e a autonomia do desenvolvimento: **o software foi totalmente planejado, codificado e entregue em menos de 24 horas de produção, com um layout totalmente construído à mão**.

O objetivo foi testar minha agilidade técnica, criatividade visual e capacidade de entrega sob pressão, consolidando um fluxo completo de manipulação de dados em um curto espaço de tempo.

---

## ⚡ Destaques do Projeto (Sprint de 24h)
- **Desenvolvimento Ágil:** Aplicação construída do zero, focando na eficiência do código e na entrega de uma solução funcional em tempo recorde.
- **CRUD Perfeitamente Funcional:** Centralização das quatro operações essenciais no banco de dados (**C**reate, **R**ead, **U**pdate, **D**elete) aplicadas ao gerenciamento do ecossistema FIFA, rodando sem erros.
- **Layout Feito à Mão:** Design da interface gráfica totalmente estruturado, posicionado e estilizado manualmente dentro do Windows Forms, garantindo uma identidade visual própria e limpa para o usuário.

## 🛠️ Stack Tecnológica
- **Linguagem:** C# (.NET)
- **Interface:** Windows Forms Application (Layout Customizado)
- **Banco de Dados:** MySQL
- **Ambiente de Desenvolvimento:** Microsoft Visual Studio
